# 打印快捷工具

Windows 桌面程序，用于批量扫描、导入、校验和快捷打印报销票据 PDF。

本分支为本地专票功能快照；main保留既有安装、图标和托盘更新，本分支尚未与其合并。

## 主要功能

- 选择总文件夹后自动后台扫描各层子文件夹的 PDF/图片/ZIP；明细显示相对路径，同名文件可区分。也支持选择多个文件或把文件直接拖入附件区域。
- ZIP 会自动读取内部 PDF，并在明细中显示“压缩包 / 内部路径”；非 PDF 成员会排除。普通 PDF 自动识别页数、方向、铁路电子客票、增值税专用发票和票面金额。
- 相同内容只保留一份，ZIP 外 PDF 优先；跳过的重复项会记录来源。ZIP 中的 OFD 不处理，可使用同票 PDF。
- 未识别金额的 PDF 仍可打印；金额仅用于汇总。ZIP 内单个文件损坏、读取失败或超过限制时会跳过并记录原因，继续处理后续可读 PDF。
- 支持 A5、A4 纸张；主界面提供智能、标准、高清、快速四项常用预设，高级规则中提供双面、横向实际、纵向实际、横向适配和纵向适配。
- 支持自由设置铁路票、专票、其他 PDF 和复印份数及打印方向。专票默认 2 份，可在“专票份数”中输入或点箭头调整为 1–99 份；已导入明细和预计作业即时更新，选择和移除状态保留，重启后记住合法数量。复印每次启动默认 0，手动输入 1–99 的整数后才启用。
- 打印规则支持 0–50 mm 四边统一边距拖动，调整值自动持久化到下次启动。
- 支持 JPG、JPEG、PNG、BMP、TIFF、WEBP 图片识别；图片会转换为缓存 PDF 后统一打印。
- 支持“合并/转换 PDF”：将选中文件或全部明细合并为新的 PDF，原文件不会被覆盖。
- 主界面提供选择打印、打印全部、打印预览、打印记录和打印规则校验；按份数打印、盖章和打印校准页集中在高级功能区。
- 启动时直接显示附件明细，隐藏蓝色上传卡片；高级功能默认收起，可从来源区的“展开高级功能”打开。高级规则在“打印规则”区域加宽下拉选择，规则说明独立一行并自动换行。
- 支持选择印章图片、指定页或全部页盖章、普通盖章和齐缝章；盖章会生成新 PDF，原文件保留。
- 支持最小化到 Windows 系统托盘；可从托盘菜单恢复窗口或退出程序。
- “校验规则”检查方向、纸张、尺寸、可打印区域及重复导入，显示已跳过重复来源，不提交打印作业。
- Windows 拖放使用 TkDnD `<<Drop>>` 事件，包含路径数量/长度校验、目标区域校验、异常隔离和失败后继续运行保护。
- 拖放失败时程序保持运行，并在状态栏和日志中提示使用“选择附件”重试。
- 文件明细支持按住鼠标上下拖动连续多选；指针停在列表上下边缘时自动滚动，松开即停止。也支持 Ctrl/Shift、全选按钮和 Ctrl+A；点击“移除所选（数量）”批量移出本次打印列表，磁盘原文件保留。
- 导入开始即显示源文件名，后台每识别完一份就补齐页数、金额、方向等明细；批量进度分批处理，追加刷新保留选择，导入失败恢复原列表。
- 使用 Windows 本地打印接口，不打开 WPS。

## 使用方法

1. 双击 打印快捷工具-v1.2.21.exe。
2. 点击“选择文件夹”选中票据总文件夹，程序自动扫描全部层级并逐条显示明细；不必逐个选择子文件夹。也可点击“导入文件”或“继续添加附件”，或把 PDF、图片/ZIP 拖入附件明细区域。
3. 导入或拖入文件后，程序自动识别并切换到“智能”预设；ZIP 内 PDF 会展开到明细列表。
4. 选择打印机、A5/A4、打印预设、份数、方向，并拖动“打印边距”调整四边留白。
5. 可选中明细后点击“合并/转换 PDF”；未选中时合并全部明细。打印前可点击“打印预览”查看纸张、方向、缩放和边距后的版面。
6. 打印前可点击“校验规则”；该操作不会提交打印作业。
7. 需要部分打印或移除时，按住鼠标左键从起始文件向下拖动多选，松开后点击“选择打印”或“移除所选”；也支持 Ctrl/Shift、全选及 Ctrl+A。
8. 需要统一份数时，将默认 0 的复印份数手动改为 1–99，打开高级功能并点击“按份数打印所选”。
9. 需要全部打印时，点击“打印全部”并确认。
10. 需要盖章时，在高级功能的“盖章设置”中选择 PDF、印章图片、页数和模式，再点击“盖章所选文件”。
11. 点击“打印记录”可查看提交作业、队列观察、失败原因；当前附件仍是同一批源文件时可以确认后重试。新记录保留每个文件的原份数，重试可能重复输出已提交作业。

程序完成提交不等同于人工确认实际出纸，打印后仍需检查纸张、方向和版面。

## 源码运行

使用包含 `requirements.txt` 依赖、Tkinter 的 Python 3.12–3.14：

    python app.py

无界面扫描：

    python app.py --scan-folder "C:\path\to\folder" --output result.json

## 测试

    python -m unittest discover -s tests -v

    .\build.ps1

## 专票识别规则

依据 PDF 可提取文字中的“增值税专用发票”或“增值税电子专用发票”标题识别，兼容电子发票括号标题及标题空格、换行。普通发票标题先于专票词出现时按普通发票处理，避免备注提及专票造成误判；不凭“专票”文件名判断。ZIP 内 PDF 使用相同规则；明确专票标题优先于 20 位数字文件名的铁路兜底。份数以整份 PDF 为单位，不拆分同一 PDF 内不同类型页面。

纯图片和无可提取文字的扫描件仍不自动 OCR，无法保证专票识别；打印前请核对明细分类和份数。专票输入为空、非整数、0 或超过 99 时禁止打印，改为合法值后恢复。

目录链接和文件符号链接会跳过并记日志；不可读取的目录会明确报错，防止把部分扫描当作全部完成。所有受支持文件都参与识别，纯扫描图片仍不进行 OCR。图片/ZIP 新缓存按来源路径独立保存，旧缓存保留；旧版图片/ZIP 历史记录若无法匹配新版明细，应重新从当前明细发起打印。

`tests/test_workflows.py` 使用真实 Tk 控件、隔离测试数据和模拟打印后端验证回调流程，不向打印机提交作业。它覆盖导入中途明细、失败恢复、紧凑布局、扫描、ZIP/图片、规则、边距、预览、盖章、导出、记录重试及退出。v1.2.15 另通过 Windows 原生多文件对话框导入 82 个受控附件，验证明细、选择、滚轮和高级区；不能视为资源管理器真实拖放、托盘菜单点击或实际出纸验收。
